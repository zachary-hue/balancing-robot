# firmware

My own code for the robot. I write each step as a small test sketch that has to work before I move on.

- [ ] 1. Blink, and print to the serial monitor
- [ ] 2. Spin one motor with PWM
- [ ] 3. Count encoder pulses and print the speed
- [ ] 4. Read raw IMU data over I2C
- [ ] 5. Turn the IMU data into a tilt angle
- [ ] 6. A PID controller that holds the angle
- [ ] 7. Combine everything into the full balance loop
- [ ] 8. Serial commands to change the gains while it runs

I read the reference repo for ideas, close it, then write my own version and compare.
